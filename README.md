# django_project

## Описание:

django_project - это интернет магазин, который будет разрабатываться в течение нескольких домашних заданий.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/RomanBatyuk/django_project
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте проект в PyCharm.
2. Теперь вы можете поучавствовать в учебном процессе ;)
